# zipapp(.pyz) 빌드용 의존성 핀.
#
# pyproject.toml 은 개발 편의를 위해 범위로 지정(questionary>=2.0,<3.0)하지만, 배포본에
# 들어가는 산출물은 빌드 시점마다 달라지면 안 된다. 여기에 버전과 해시를 고정한다.
#
# scripts/build-config-pyz.sh 가 --require-hashes 로 설치하므로, 이 목록에 없는 전이
# 의존성이 생기면 빌드가 실패한다. 그때 아래 절차로 갱신한다:
#
#   python3 -m pip download --only-binary=:all: -d /tmp/whl questionary rich
#   for f in /tmp/whl/*.whl; do sha256sum "$f"; done
#
# 전부 순수 Python(py3-none-any)이어야 한다 — 네이티브 확장이 섞이면 아키텍처마다
# 다른 산출물이 필요해져 단일 파일 배포가 성립하지 않는다.
